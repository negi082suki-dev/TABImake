# TabiMake

旅行プラン作成と旅の記録をまとめた、インストール可能なPWAのサンプルです。

## できること
- 旅行プランの条件入力と、ChatGPTなどに貼り付ける依頼文の作成
- 写真付きの日記（自由記入／質問形式）
- 日付・場所の記録
- お気に入りの切り替え
- アルバム表示、記録の削除
- IndexedDBによる端末・ブラウザ内保存
- PWAとしてホーム画面／デスクトップに追加

## 大切な注意
- データは基本的に、このブラウザ・端末の中に保存されます。他の端末とは自動同期されません。
- ブラウザのデータ削除、端末故障、サイトデータの消去などで記録が失われることがあります。大切な写真は別にもバックアップしてください。
- このサンプルにAI APIは接続されていません。プラン作成画面で依頼文を作り、ChatGPTなどに貼り付けて使います。
- インストール可能なPWAにするにはHTTPSで公開する必要があります（localhostでの開発時を除く）。index.htmlをファイルとして直接開くだけではインストール機能やService Workerは動作しません。

## 起動・公開方法
1. ZIPを展開します。
2. フォルダ内のファイル一式をHTTPS対応の静的ホスティング（例：GitHub Pagesなど）にアップロードします。
3. 公開URLをスマホ／PCのブラウザで開きます。
4. 対応ブラウザのメニューから「ホーム画面に追加」「アプリをインストール」などを選びます。

GitHub Pagesを使う場合は、リポジトリを作成してファイル一式をアップロードし、Settings → Pagesから公開設定を行います。公開後のURLを開いてください。
